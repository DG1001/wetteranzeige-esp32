Wetteranzeige

für das Sunton-Board ESP32-8048S043 (4,3", 800×480, Touch) · Version __VERSION__

Dein Browser kann nicht auf USB-Geräte zugreifen. Bitte Chrome oder Edge auf einem Computer verwenden (nicht auf dem Handy). Die Installation braucht eine sichere Verbindung (https).

So geht's

  1. Board mit einem USB-A-auf-USB-C-Kabel an den Computer anschließen. Mit einem C-auf-C-Kabel bekommt dieses Board keinen Strom.
  2. Auf „Auf das Board installieren“ klicken und den Anschluss wählen (meist „USB Serial“ bzw. „CH340“). Bei einer Erstinstallation „Gerät löschen“ bestätigen. Das Übertragen dauert einige Minuten.
  3. Danach zeigt das Display einen QR-Code: damit mit dem WLAN „Wetteranzeige“ verbinden, dann WLAN und Ort eintragen. Fertig.

Gut zu wissen

Die Einstellungen erreichst du später im Heimnetz unter http://wetteranzeige.local (Benutzer admin, die PIN zeigt das Display nach 2 Sekunden Drücken). Dort gibt es auch Updates: Datei wetteranzeige-…bin aus den Releases hochladen, die Einstellungen bleiben erhalten.

Wird kein Anschluss angezeigt: anderes Kabel probieren (manche Kabel laden nur). Unter Windows braucht der Wandler eventuell den CH340-Treiber. Klappt die Verbindung nicht, beim Klicken auf „Verbinden“ die Taste BOOT am Board gedrückt halten.

Wetterwarnungen, Radar, Pollenflug und Biowetter gibt es nur für Deutschland.
